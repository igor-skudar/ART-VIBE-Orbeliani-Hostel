# ART VIBE Orbeliani Hostel

A responsive one-page website built for **ART VIBE Orbeliani Hostel**, a cozy hostel located in the heart of Tbilisi, Georgia.

## Live Demo

**[View the live site →](https://igor-skudar.github.io/ART-VIBE-Orbeliani-Hostel/)**

## Features

- Fully responsive layout, from small mobile screens up through large desktop, with dedicated breakpoints for room cards, hero, and amenities
- English and Russian language switcher with no page reload — all text, alt attributes, and aria-labels update instantly via `data-i18n` attributes
- Hero section with a full-viewport background image on mobile and half-viewport on desktop, headline, and call-to-action button linking to the booking section
- About section introducing the hostel, with supporting photography
- Rooms section featuring 4 room types (Private Double, Private 4-Bed, Common Dormitory, Female Dormitory), each with pricing, a feature list, a swipable image gallery with dot indicators, and a "Reserve Now" button; room image/info sides alternate on desktop for visual rhythm
- Amenities section listing hostel amenities (WiFi, kitchen, laundry, terrace, air conditioning, heating, central location, movie nights, lockers, and English/Russian-speaking staff) alongside a lifestyle photo
- Location section with an embedded Google Maps view and the hostel's address
- Contact section with direct WhatsApp, Telegram, and Email buttons, plus a footer with a back-to-top link
- SEO and social sharing metadata: Open Graph and Twitter Card tags, canonical URL, meta description, and search console verification tags
- Design system built entirely on CSS custom properties (colors, spacing, typography, radius) for easy theming and consistency

## Built With

- HTML5
- CSS3
- Vanilla JavaScript (ES modules) — language switching and gallery/dot syncing, no dependencies
